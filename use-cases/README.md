# Cas d'usage

Cette rubrique regroupe des exemples complets d'exploitation des flux FiNESS.

Chaque cas d'usage contient :

- le contexte ;
- les flux utilisés ;
- les règles de gestion ;
- le mapping des données ;
- les scripts associés ;
- des exemples de fichiers d'entrée et de sortie.

## Cas disponibles

| Cas | Description |
|------|-------------|
| json-to-table | Transformation d'un flux JSON FiNESS+ vers un modèle tabulaire |
